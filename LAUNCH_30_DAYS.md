# 30-Day Zero-Budget Launch Plan (B2B Software Comparisons)

Goal: get the site indexed, apply to affiliate programs, and produce the first measurable clicks/sales. No ad spend until organic conversion is proven.

## Week 1 - Foundation (mostly automated)

- [x] 9 comparison pages generated and deployed
- [x] Sitemap + robots.txt generated
- [x] Affiliate disclosure on every page
- [ ] Replace "Find official site" links with approved affiliate links as programs approve
- [ ] Submit sitemap to Google Search Console (free) and Bing Webmaster Tools
- [ ] Create Gumroad listing for the B2B buying guide (free)

## Week 2 - Content depth

- [ ] Generate 5 more comparisons: e-signature, cloud storage, video conferencing, help desk, marketing automation
- [ ] Add internal links between related pages (CRM <-> email marketing, project management <-> help desk)
- [ ] Add a "How we evaluate" page and an "About / Disclosure" page (trust signals)

## Week 3 - Free distribution

- [ ] Post 2 value-first threads on LinkedIn about software selection (no link spam)
- [ ] Answer 3 relevant questions on Reddit/Quora with genuinely useful criteria, link only when relevant
- [ ] Create 5 Pinterest pins linking to comparison pages
- [ ] Email 3 small newsletters offering a free comparison resource (no paid placement)

## Week 4 - Measure and iterate

- [ ] Check Search Console: impressions, queries, CTR
- [ ] Identify the 2 pages with the most impressions; improve them first
- [ ] Apply to 2 more affiliate programs
- [ ] If any page converts, consider $5-10/day ads to that page only

## Reinvestment

- 100% of net revenue reinvested until $500/month.
- First purchases: domain (~$10-15/yr), then content/backlinks.
- See `finance/reinvestment_policy.md`.

## Honest expectations

- SEO indexing takes 2-8 weeks; meaningful traffic typically 3-6 months.
- Most new pages will not rank. The winners compound.
- Affiliate approvals can take days to weeks; some reject new sites.
- This is a portfolio strategy, not a guaranteed income.
