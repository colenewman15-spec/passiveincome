How it works

  • All processing happens locally in your browser — files are never uploaded.
  • Merge combines multiple PDFs in the order listed.
  • Split extracts every page (or a range) into a ZIP of single-page PDFs.
  • Rotate re-saves pages rotated 90°.
  • Compress re-encodes the PDF with object streams for a smaller file.
